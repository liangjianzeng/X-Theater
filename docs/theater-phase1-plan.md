## 0. 一期一句话目标与验收总线

**目标**：不依赖任何外部生成供应商，跑通「一句话/小说 → 八阶段 → 带标识可交付竖屏成片」的**自有能力闭环**，并完成 Spark 验收与首批自生产。

**一期验收总线（= M2 出口条件，全部满足才算完成）**：

| # | 验收项 | 判据（证据物） |
|---|---|---|
| V1 | 全链路自部署成片 | 一句话→60s 竖屏成片，人工决策点 ≤5；链路中零外部生成 API 调用（job 账本可证，worker_type 全部 self-host） |
| V2 | 生图先行达标 | 定妆照单张 <45s（5060 Ti 实测 n≥20）；5060 Ti qwen-image-2.1-turbo-Q5_K_M 显存实测 ≤16G；Spark H3-Image 常驻服务 2K 出图实测记录 |
| V3 | Spark 验收基准 | Spark×1 单发 60s ≤60min 实测记录＋批量外推模型（5s@720p/60s@768p 双档计时，n≥10） |
| V4 | 裸浏览器全功能·**双端同等** | Playwright 双 lane 冒烟流入 CI 且全绿：**桌面 lane 全量；H5 lane 覆盖全部界面主路径**（核心链路 首页→卡流→开机→审片→导出 双端各跑一遍，其余界面 H5 主行动可达＋截图回归）——发起人 2026-11-20 裁决「所有 UI 必须 H5 兼容、移动端同等可用」 |
| V5 | 成本透明与影子记账 | 每镜成本穿透可查；billing_event/wallet_txn 对账不变量 property 测试通过；initiated_by/review_record 全量落库 |
| V6 | 运营最小后台 | 复审工作台可处置一条真实内容留痕；告警（worker 心跳/队列积压/失败率→IM）触发演练一次 |
| V7 | 合规边界自查 | 邀请制内测名单留档、全量水印＋显式/隐式标识、prompt 黑名单生效、协议文本挂出；备案材料包预启动（不阻塞） |
| V8 | 二期预留面 | 多供应商路由表 schema/UI 槽位、ProviderAdapter 接口、BYOK/价目入口以占位呈现（点击明示「商业化阶段开放」）；技能候选池采数字段就绪（adopt_diff 等，UI 规范 §13） |
| V9 | **L2 Copilot（runtime 双模式：A＝DSH 实例承载·默认／B＝自建 mock 双跑，ADR-003 D6/D7）** | 「自然语言→工具调用→必答门→执行」5 类真实任务全通（查询/重拍/择优/成本/进度）；红队三案（间接注入/昂贵动作绕过/跨租户探测）**双模式各跑一遍零越权**；实例工具面白名单化（无 shell/文件/代码执行面）；trace 100% 落 AgentRun；**AgentRuntimeAdapter 契约测试绿（换 runtime 上层零改动）**；**副驾＝右侧常驻驾驶栏（对话/任务/审批三视图，UI 规范 §5.2）桌面默认可见＋H5 中央一级 tab** |
| V10 | **配乐标准版（发起人 2026-11-20 裁决：一期自部署生乐服务）** | 一集按情绪标签自动配乐（人工情绪命中评分 ≥4/5）＋试听/换一批/重新生成闭环；交付预检**音乐双许可项**（模型协议＋产物使用权）拦截生效；配乐段位入 S15 注册表；H5 同权（试听/换曲拇指主行动） |

**一期不做（范围外，出现即范围蔓延）**：商业 API 对接、托管弹性、BYOK、实名、对外报价与扣费、原生 App、时间线全控、口型驱动、技能市场、**任何第三方宿主/外部产品联动与视觉对齐（剧场为完全独立产品，发起人 2026-11-20 裁决）**。

## 1. 里程碑与闸门（12–16 周 · 双里程碑）

```
W1 ─────── W7 │ M1 闸门 │ W8 ─────── W12 │ M2 闸门 │ W13–16 缓冲+内测运营+二期准备
    里程碑一：样片闭环        里程碑二：成片验收
```

### M1 闸门（第 7 周末）——「一句话到样片」

| 检查项 | 通过标准 |
|---|---|
| 产品链路 | 一句话/小说 → 策划案 → 演员表（定妆 4 候选/人）→ 风格圣经 → 镜头表 → 分镜图 → **样片 mp4**（分镜图+TTS+配乐）全程可视可批 |

| 自部署 | C1/C2/C3 完成：两台机器环境基线、模型资产台账（含许可留档）、生图链路 |

| 演示 | 用真实小说一章现场跑样片 |

### M2 闸门（第 12–14 周，缓冲至 16）——「样片到成片验收」

| 检查项 | 通过标准 |
|---|---|
| 自部署视频 | LTX-2.5（5060 Ti 量产档）＋FastH3（Spark 高价值/闲时档）批量 i2v：队列/进度/重拍/择优/预算护栏全活 |
| 合成交付 | 成片合成＋显式/隐式标识强制＋平台规格导出（抖音预设）；验收卡 |
| 一致性 | 评分门（标定表）软→硬上线；像不像分入 take 元数据 |
| 机审运营 | prompt 机审＋抽帧机审＋复审工作台＋申诉；告警演练 |

## 2. WBS 工作包分解（A 产品 118pd ＋ B 平台 122pd ＋ C 自部署 40pd ≈ 280 人日）

> pd＝人日（中性估算）；「依赖」为硬前置；DoD＝完成的定义。**生图先行纪律**已排进依赖：A4/A6 的图片部分先于 A7。
> **双端裁决（发起人 2026-11-20）**：全部界面 H5 兼容、移动端同等可用（UI 规范 §1 三形态/§3.7 移动壳）。A 工作流 95→105、总盘 240→250（基线＝计划 v1.0 重构口径，与评审 T9 粗估 240 构成不同）；**砍单只砍功能深度，不砍界面双端覆盖**（见 §5）。
> **L2 裁决（发起人 2026-11-20）**：对话副驾一期必须上线，runtime 双模式（模式 A 已部署 DSH 承载·默认／模式 B 自建·同契约兜底，ADR-003 D6/D7）。新增 A9 对话前端 8pd＋B10 runtime 控制面 8pd＋B9 写侧工具 +2pd（250→268）；**L2 与双端同为不可砍项**（§5 底线）。同日追加裁决：副驾为**主要功能（辅助驾驶）不得默认隐藏**——桌面右侧常驻驾驶栏／H5 底栏中央一级 tab（UI 规范 §5.2，含对话/任务/审批三视图，pd 不变）。
> **配乐裁决（发起人 2026-11-20 追加）**：一期上**标准版**——自部署生乐服务（ACE-Step 首选·5060 Ti，Stable Audio Open 备选 W1 核证），新增 A10 配乐 UI 5pd＋B11 配乐服务 7pd（268→280）＋验收 **V10**；带唱/主题曲（YuE 级）二期；配乐不新增必答门（默认自动，可整体关）。

## 5. 人力预案与砍单清单

- **双人为基准**（1 全栈产品 ＋ 1 平台；发起人兼产品设计/测试）；280pd（含双端化 ＋10pd、L2 ＋18pd、配乐 ＋12pd）≈ 13 周建设＋缓冲。**容量口径**：2 全职＋发起人 ≥0.5 折算 ≈21pd/周，12–16 周才能装下 280pd——**发起人时间不可用即等同触发 §5.1**；**批单人则启动 §5.1**（周期仍 12–16 周，不延期）。
- **§5.1 单人预案：明确交付子集（按序砍，砍后 ≈110–120pd 可被单人×缓冲期吸收）**：三视图 turnaround → 定场照 ×3 → 音色卡试听 → 局部重绘 → 分镜图逐格换图（保留换图不能拖拽）→ 参考图四槽位（改单槽上传）→ 首跑预生成样例（改手工配置一个）→ **配乐降格＝固定曲库顺序配乐（B11 缓行，V10 顺延内测段补）→ A5/A7 功能深度降级（美术仅默认风格、拍摄护栏只暂停不建议）→ L2 深度降级：保查询/进度/成本类只读工具＋对话面与审批收件箱，重拍/择优类写侧工具顺延内测段（V9 的 5 类任务验收相应顺延至缓冲期，白名单/必答门/trace 底线不动）**。**砍单只砍功能深度，被砍功能的 H5 形态随之消失即可，不得反向砍「界面 H5 覆盖」——剩余全部界面仍须双端同等**。**不可砍底线**：五级树/账本/幂等/标识强制/复审工作台/影子记账/Playwright 冒烟/**全界面双端（H5 可用，UI 规范 §1 三形态/§3.7 移动壳，H5 lane 入 CI）**/**L2 Copilot 常驻面与治理底线（DSH 承载，发起人必上项，A9+B10+V9）**/全部 V1–V3＋V9（写侧 5 类任务按上述顺延规则）。
- 每周固定动作：周五 nightly 冒烟报表评审＋风险登记（对照总文档 §8）；里程碑前 3 天冻结新功能。
