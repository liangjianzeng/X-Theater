# ADR-002 · 端侧技术选型：Web SPA 单一构建（独立产品）

> 状态：**已决策（2026-11-20），同日按发起人独立产品裁决修订**
> 裁决要点：**剧场是完全独立的产品线**——自有品牌、自有设计体系、自有账号与计费；**与任何既有应用/宿主零绑定、零对齐义务**。第三方宿主承载（OEM 后台、未来的桌面应用等）只是**商用期可选渠道**，不是产品前提。
> 关联：[theater-ux-design.md](theater-ux-design.md) §1/§5（端侧规格）· [ADR-001](theater-infer-backend-adr.md)（算力后端）

---

## 0. 结论

1. **剧场 = Web SPA（单一构建），两个正式宿主**：桌面浏览器（重度生产的舒适区）/ 移动 H5（**全功能同等的正式宿主**，红果式滑动审片是其代表场景而非全部）——发起人 2026-11-20 裁决：**所有界面必须 H5 兼容实现，移动端同等可用**（逐界面形态见 [UI 规范 §1 三形态/§3.7 移动壳](theater-ui-interaction-design.md)）；**在裸浏览器里全部功能可用**，不要求任何宿主存在；
2. **第三方宿主（OEM iframe、未来桌面应用内嵌等）＝商用期可选渠道**：以通用契约接入（deep link + 一次性 code SSO + postMessage 事件桥），**P0/P1 不实现、不排期、不做任何设计/视觉/账号对齐**；
3. **产品身份铁律**：剧场有自己的 URL、账号体系（手机 OAuth 登录）、计费与品牌；任何接入方都是渠道，不是依赖。

---

## 1. 为什么是 Web SPA（而不是桌面壳 / 移动原生）

| 维度 | Web SPA | 桌面壳（Electron/Tauri 等） | 移动原生/Flutter | 判定 |
|---|---|---|---|---|
| **台本/台词编辑器**（核心生产场景） | 浏览器原生 textarea/contenteditable，中文 IME、光标、粘贴格式全是用户肌肉记忆 | 同 Chromium，可行但多一层发版 | IME 组合输入短板，中文逐句精修体验打折 | **Web 胜** |
| 发版速度 | CDN 即时全量（体验活要天级调） | 壳跟版/热更基建成本 | 壳跟版；Web 线二流 | **Web 胜** |
| 多端覆盖 | 一份构建：桌面/H5/嵌入全白送 | 桌面 only | 桌面缺失或二流 | **Web 胜** |
| 协作分发 | URL 即协作（发链接给制片人审片，免安装） | 要求装同一 App | 同左 | **Web 胜**（B 端多角色审阅刚需） |
| OEM/平台嵌入 | URL/iframe＋主题参数即可 | 难嵌入异构系统 | 难嵌入 | **Web 胜** |
| 本地/原生能力 | 弱项 | 强项 | 强项 | **平**——剧场零本地算力、零本地硬件需求，强项无用武之地 |

**一句话**：剧场是零本地算力的云产品，桌面壳/原生的优势全部落空，而它的两个命门场景（中文台本编辑、链接协作审片）恰是 Web 的主场。

## 2. 宿主架构

```
Theater Web SPA（一套构建，CDN + hash 资源 + no-cache index）
 ├─ 宿主① 桌面浏览器            生产主战场（八阶段工作台）
 ├─ 宿主② 手机 H5（微信内/浏览器） 全界面移动形态：创作/选角/拍摄批复/审片/交付/通知
 └─ 宿主③ 第三方宿主 iframe/内嵌（商用期可选渠道，契约预留不实现）
公共底座：自有 OAuth 登录 · feature detection · postMessage 桥（可选，永不硬依赖）·
        响应式断点 · 触屏手势 · 自有设计 token 体系（不参照任何外部产品）
```

## 3. 第三方宿主接入契约（v0.1 预留，商用期按需启用；P0/P1 不实现）

| # | 项 | 规格 |
|---|---|---|
| 1 | 唤起 | `https://<theater>/?embed=<host_id>&code=<一次性>`；code 由宿主后端向剧场后端申领（服务端签名：时间戳+nonce+secret），TTL 60s、单次、绑定宿主账号；**落地页即刻 POST 兑换＋history.replaceState 清 URL＋`Referrer-Policy: no-referrer`（code 不落日志/历史/Referer）** |
| 2 | SSO | Web 端以 code 换 session（JWT ≤15min＋服务端会话吊销表）；**兑换原子燃烧（唯一约束/SETNX 防并发双兑）；PKCE 式绑定：宿主生成 verifier、申领时登记 hash(verifier)、兑换时校验；昂贵动作（开机/导出/扣积分）前强制在线校验会话；宿主登出调用 revoke**；**未绑定宿主的用户直接走剧场自有登录**（承载态≠强制绑定态） |
| 3 | postMessage 事件（最小集） | `theater:ready{version}` · `theater:export{assetId,url,title}` · `host:theme{dark/light}`；协议版本号管理，宿主不认识的 event 忽略 |
| 4 | 会话卫生 | 嵌入式会话用隔离上下文；index.html no-cache；短 TTL 兜底 |
| 5 | 降级 | 宿主容器异常 → 「在浏览器中打开」直达 URL，功能降级不阻塞 |

## 4. 可移植性红线（保证「脱离任何容器」成立）

1. **宿主零依赖**：检测 `window.__THEATER_HOST__` / postMessage 可用性只做体验增强（主题/导出回执），任何功能路径不得要求桥存在——裸浏览器过全量回归；
2. **桥协议统一 postMessage**，不做宿主注入式 JS bridge（保 OEM/H5 同构）；
3. 审片手势纯浏览器事件实现（Pointer Events），不依赖宿主；
4. 下载＝标准浏览器下载；上传＝标准 file input ＋ 对象存储直传。

## 5. 技术栈（轻决策，随实现复审）

React + Vite（营销/SEO 页可上 Next）；TanStack Query（任务轮询/SSE 状态）；轻量原子状态（zustand）；Tailwind + **自有设计 token 体系**；故事板拖拽 **pragmatic-drag-and-drop（或 vendor pin dnd-kit 6.3.1——上游已停更，二选一）＋ Pointer Events 自绘兜底**；时间线自研轻量三轨（视频/音频/字幕，只做「AI 产物的组装」不做通用剪辑）；播放器原生 `<video>`（mp4 竖屏，不引重型播放器）；错误监控 Sentry + feature flags；**E2E：Playwright 双 lane 冒烟（桌面全量 + H5 全界面主路径，含审片手势）——「裸浏览器全功能·双端同等」的验收证据，入 CI**。

## 6. 分期

| 阶段 | 端侧动作 |
|---|---|
| **P0（一期）** | Web SPA 全功能**双端同等**（桌面响应式 + **H5 全界面可用**，UI 规范 §1/§3.7）＋自有登录（邀请制内测，实名豁免至二期）＋**Playwright 双 lane 冒烟（验收证据入 CI）**；无任何宿主联动项 |
| **P1（二期）** | 席位协作与分享链接完善；第三方宿主接入契约仅出文档不实现；PWA（离线壳可选） |
| **P2/P3** | OEM iframe 白标契约按需启用（签名＋主题参数＋免登）；开放 API |

## 7. 风险与对冲

| 风险 | 对冲 |
|---|---|
| 故事板网格/多视频预览 Web 性能 | 虚拟列表 + 缩略图先行、点开才载高清 + 预加载策略 |
| 第三方宿主接入时的账号割裂（商用期议题） | 承载态 code 换 session 统一身份；未绑定给「绑定账号」引导，不强制造依赖 |
| 会话漂移（宿主登出/权限变更） | 短 TTL + 吊销尽力而为 + 敏感操作二次确认 |
| Web 长任务进度可靠性（SSE 断连） | WSS/SSE＋轮询降级双通道，以 job 账本为唯一事实源 |
| 团队 Web 栈空缺 | 剧场是新产品线本就要建；按 §5 技术栈一次性立规 |
