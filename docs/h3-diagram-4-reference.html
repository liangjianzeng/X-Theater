▶ 横切纪律（每一幕都受约束）

模板四元组锁定sha16 × ComfyUI commit × 节点 commit × 权重清单，manifest 校验不过即拒跑（COMFY_TMPL_DRIFT）
内存族常驻h3video / h3image 同族连续出片不卸载；跨族才 POST /free；ram_free<8G 才释放（Spark 统一内存纪律）
身份门控 0.6ArcFace ≥0.6 过审；不达标 swap 换回源脸复核；2 次重试仍不过 = 真错误进补拍梯子
失败补拍梯子worker 抛错 → 系统免费重试 ≤2 次（共 3 跑）→ failed＋告警；绝不静默回退造假
预算护栏＋CAS成本>预算×120% 整集暂停；卡 ver / estimate_ver 不符 → 409 STALE 防并发拍板
aireview 拍板机检C1/C2/C4/C6 每个拍板点多人格规则审查（编剧/观众/制片/选角/造型/统筹/摄影/配音）；真 LLM 到位换 lane 不换骨架
影子记账Σbilling == episode.cost_cents 对账不变量；免费任务不记不计；用户面只显示「自部署·高价值档」
