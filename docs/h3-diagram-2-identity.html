第 2 幕

初始定妆：确立「角色身份源」

业务场景 · 用户三入口确认制
身份从这里锁定：用户上传的原图就是定妆终稿（也可以让 H3 按提示词生成候选再挑）。此后所有环节（试镜、分镜、视频）都以这张图为身份根，不再自动随机生成新脸。
业务层C2 卡
每个角色三选一：① 上传原图 ② 提示词生成初始图 ③ 继承旧集定妆（跨轮沿用，脸不重掷）→ 卡上点「确认」
编排层REST API
① POST /api/episodes/:id/castref/upload?role=X（raw PNG/JPG ≤16MB，router 支持 raw body） ② POST …/castref/generate {role, prompt} → cast_init job ③ POST …/castref/confirm {role, file}
模板层生成入口
cast_init 走 h3-image-cast 纯 t2i：864×1536 精确 9:16（32 倍数）· 半身景别·面部清晰锐利；产物追加为该角色候选「AI 初始图」
模型层门控模型
confirm 时 facegate buffalo_l（insightface，:8195）做人脸存在性机检——no_face 拒绝确认；ArcFace embedding 即身份基准
产物层固化
var/assets/cast/<file>.png → 写入 cast.refImage；全员确认齐 → 自动派 screen_test（每角色 1 条，engine.activeOf 防重派）
▼全员 refImage 就位 → 自动派 screen_test（★ 本次调整核心幕）
第 3 幕 ★

试妆试镜（C2S）：一条视频锁死「脸＋体态」

业务场景 · 高保真身份采集
为什么用视频不用照片：一张定妆照只有一个角度；分镜需要的左右 3/4 侧脸、仰头、低头等姿态各有专属参考帧。用初始图直接作首帧生成一条多角度试镜视频，再逐帧打分挑帧——背景和道具只是壳，人脸五官、体态、眼神、表情才是要高保真的本体。
业务层C2S 卡
用户看：试镜视频 ＋ 7×2 抽帧网格 ＋ 逐帧分数/角度 ＋ 确认清单（五官脸型/身材体态/服装细节/多角度）→ 勾选拍板；不满意 → reject 附意见 note → 自动重出试镜
编排层screen_test job
lane 固定 imgspark；流程：ffmpeg cover 裁切初始图 → 上传 Spark → FL2VA 真跑 → 抽帧 → 逐帧打分 → onScreenTestDone 出 C2S 卡
模板层h3-fl2va-video
节点链：LoadImage(FIRST_FRAME)→MiniMaxH3ImageToVideo→SamplerCustomAdvanced(res_multistep)→VAEDecode+VAEDecodeAudio→CreateVideo(24fps)→SaveVideo
参数：736×1312（32 倍数等比裁切）· 124 帧 / 5.17s · turbo 4 步 · timeout 1500s · 动作提示词＝正面→左 3/4→右 3/4→仰头闭眼→回眸微笑（覆盖分镜所需头部角度）· 用户 note 追加尾部
模型层权重
minimax_h3_fl2va_pruned_int8 20.97G 首帧→声画 DiT　＋　fl2v_turbo_4step LoRA 1.96G（40+步→4步蒸馏）　＋　video VAE 5.21G ＋ audio VAE 0.61G（原生声画）　＋　qwen3vl_32b TE 15.7G
产物层抽帧＋固化
<jobId>_screentest.mp4 → ffmpeg select=not(mod(n,10)) 抽 ~13 张全分辨率候选 → 逐帧 facegate ArcFace 打分（yaw/pitch 角度标签）→ <jobId>_grid.png 7×2 缩略墙
accept C2S → score≥0.6 硬线过滤 → 拷贝 var/assets/cast/<role>/views/ → 固化 st.viewRefs[episodeId][role]（分镜的身份输入源）
▼viewRefs 固化 → 自动派 storyboard_char（分镜＝选角度帧＋换背景壳）
第 4 幕

角色分镜＝「选角度参考帧 ＋ 只换背景壳」

业务场景 · 保脸分镜
分镜不再重新画人：每一镜先解析出需要的头部角度，从试妆帧库选最匹配的参考帧，然后 H3-Image edit 只替换背景与环境——人（脸/五官/发型/体态/头部角度/服装）原封不动。
业务层分镜可见
分镜首帧逐格出现在 C2/C4 卡（带 refAngle/refT 溯源：用了哪条试镜帧、什么角度）；用户 reject → 重出
编排层storyboard_char job
逐镜：shotAngleNeed(镜desc＋角色anchor) 关键词解析（仰头/低头/左侧脸/右侧脸/正面）→ pickView(viewRefs) 选该角度最高分帧（缺角度→front→全局最高分兜底；旧集回退初始原图）；同图上传缓存不重传
模板层h3-image-edit
img2img：KSampler 的 latent ← 参考帧 VAE 编码（身份像素级保真）· 宽高＝原图 /16 对齐
提示词模板：「人物保持完全不变——脸、五官、发型、体态、头部角度与参考帧一致，服装：<wardrobe 锁>。只替换背景与环境为：<该镜描述>。单幅剧照，禁止分屏拼贴。实拍电影剧照质感，浅景深」
模型层门控闭环
H3-Image DiT 20.98G（edit 模式）＋ facegate inswapper_128：出图 → ArcFace 打分，<0.6 → /swap 换回锁定源脸再打分；每镜 2 次尝试，仍不过 → IDENTITY_GATE_FAIL 进自动补拍梯子
产物层分镜首帧
var/out/<jobId>_h3charN.png → onStoryboardCharDone 按 seq 绑 shotId → 回填 C2/C4 卡 → 即图 3 第 6 幕拍摄的首帧源
