## 1. 产品概述

### 1.1 一句话定位

**面向 AI 短剧/微短剧生产团队的「导演式全流程生产线」**：用户是出品人，AI 是制片组——从一句话/小说/剧本出发，经八阶段流水线（立项→剧本→选角定妆→美术→分镜→关键帧→动态生成→合成交付）产出跨镜头角色一致、带台词配音配乐、平台可交付的竖屏成片。**先案头、后生产、每阶段有锁定门。**

### 1.2 机会摘要（详见 §2 与分册 [P]）

- 微短剧 2025 年 677.9 亿元（+34.4%），AI 漫剧（口径＝动画微短剧）189.8 亿元（**+276.3%**），2030 预测超 850 亿——产能型内容已成工业（评审注：原「AI 微短剧 2030 破 1400 亿」与总盘 1500 亿预测同源双标签、口径冲突，删；「抖音漫剧年上新 3.75 万部」查无一手出处，改引 DataEye 口径 2025 年抖音端原生漫剧上线超 6 万部；2026H1 新剧过盈亏参考线仅 1.3%——客群选「幸存者」）；
- 竞争空位（评审修订）：「全流程工作台」品类已成红海（2025-10 第三方十家画布横评点名 AniShort/巨日禄/LibTV/纳逗Pro/OiiOii/Seko/ShotLab/TapNow/万兴剧厂/小云雀；掌阅泡漫、万兴剧厂携 IP/渠道下场）——空位收窄为**五维交集**：多模型无感路由＋锁定门审计留痕＋交付级一致性评分报告＋平台交付预设＋合规内建。定位改述：「别人做了 60 分全流程，没人做 B 端可审计的那 40 分」；
- **跨集「人物/IP 不崩」是全行业公认最大痛点 = 我们的定价权**；
- 混合算力（**一期＝自部署模型为主体**，商业 API 为二期商业化质量档）＋工作流溢价，避开裸生成价格战（2026-11 现价：真地板 ¥0.5–1.25/5s，原「¥2–4/5s」为过期锚点）。

### 1.3 北极星与护栏指标

- **北极星**：周均「交付成片分钟数 / 活跃工作室」；
- 护栏：一致性达标率、采纳率（agent 产出被直接采用比例）、GPU/托管利用率、单分钟交付成本、付费转化率。

### 1.4 术语表（对外语言纪律）

## 2. 市场与商业论证（摘要，全量见分册 [P]）

### 2.1 关键市场数据

| 指标 | 数值 |
|---|---|
| 中国微短剧 2025 | 677.9 亿元（+34.4%），2030 预测超 1500 亿 |
| AI 漫剧 2025 | 189.8 亿元（+276.3%）；2030 预测超 850 亿 |
| 海外微短剧 | 2025 约 40 亿美元 → 2026 预计 50 亿美元 |
| 可商用 API 价格带（2026-11 现价） | 标准/旗舰档 ¥1.9–7.6/5s（720p）；**真地板 ¥0.5–1.25/5s**（Vidu q2-pro-fast/错峰、Seedance 2.0 mini）——原「¥2–4/5s」为过期锚点；二期商业化对接时按官方现价重新锚定 |
| C 端工具付费率 | 约 1–5%（**待校准假设**，原「3%」无一手出处）⇒ B 端与出海是利润盘 |
| 平台扶持 | 快手 8 亿分账+2 亿现金；抖音 AIGC 短剧单项目投资至 500 万 |

### 2.2 目标客群（按付费确定性）

1. **P0：AI 漫剧/AI 短剧工作室**（3–20 人，月产 500–5000 分钟，产能=平台分账收入）；
2. P1：品牌广告主/MCN（信息流、栏目剧）；出海短剧团队；
3. P2：独立创作者/网文作者（订阅引流盘）；✕ 不做 C 端随手玩。

### 2.3 差异化与护城河

① **IP 资产库沉淀**（角色卡/定妆照/音色/风格随剧集累积，迁移=弃用资产）；② **一致性可计量**（embedding 评分门 + 一致性报告交付，把痛点做成 SLA）；③ **混合算力成本优势**（量产档约为纯 API 路线的 1/10–1/3）；④ **合规内建**（标识/审核/留痕是 B 端采购前提）；⑤ **平台扶持计划绑定**（获客通道）。

### 2.4 商业模式与定价（**二期商业化议题**·假设值，私测影子记账校准后冻结）

| 档 | 月费 | 含量产时长 | 折合 | 溢出 |
|---|---|---|---|---|
| 体验 Free | 0 | 2 分钟（水印+显式标识） | — | — |
| 创作者 | ¥149 | 30 分钟 | ¥5/分钟 | ¥6/分钟 |
| 工作室 | ¥699 | 180 分钟 | ¥3.9/分钟 | ¥4/分钟（5 席位/IP 库/一致性报告/看板） |
| 制片厂 | ¥2999 起 | 1000 分钟 | ¥3/分钟 | ¥3/分钟（专属队列/SLA/私有化选装） |

- **精修包**：高价值镜头走商业 API 直通（¥4–9/5s + 服务费）；
- **BYOK 双轨（二期）**：用户自带可灵/即梦 Key，生成费直付供应商，我方收工作流订阅费——价格战免疫；
- 收入线：订阅+积分（主）→ 团队席位 → 开放 API → 私有化 → 模板/技能市场分成 → 平台合作；
- **定价冻结前置（评审修订）**：冻结前必须实测「生成分钟/交付分钟倍数」与「自部署成本占比」双参数入库；工作室档折合价（¥3.88/分钟）即盈亏平衡线，量产档内商业 API 混入率须 **≤5–8% 硬约束**（积分账本路由规则强制），精修一律走独立精修包；溢出价 ≥ 边际成本 ×1.3。一期（商业化之前）邀请制内测与自生产不对外报价。

### 2.5 单位经济（720p/分钟，量产后）

| 路线 | 成本 | 定位 |
|---|---|---|
| 自部署 worker（4090 租赁池/自购，蒸馏优化档） | **1–4 元**（前提：4 步蒸馏档＋利用率 ≥55–65%） | 二期商业化 80% 产量；**一期算力＝自有 5060 Ti＋DGX Spark（验收/自生产，不摊产线）** |
| 云/托管 ComfyUI（fal/RunPod 按秒；Comfy Deploy 现无 4090 档） | 2–25 元 | 二期峰值弹性＋公测 SLA 主力（一期仅接口预留） |
| 商业 API（可灵/Seedance/Vidu/海螺） | 15–90 元 | 二期商业化质量档＋BYOK 轨道（一期仅 UI 槽位+接口预留） |
| 机审 | 0.02–0.25 元 | 全量强制 |
| 存储+CDN | ~0.03 元 + 0.024 元/次播放 | 分层降冷 |

混合后平均 ~3–8 元/分钟（**二期商业化口径**）；工作室档毛利 40–60% 需同时满足自部署占比高＋利用率 >50%＋一次过率 >70%（**重拍倍数是第一大敏感参数**，一期影子记账实测后校准）；规模拐点修正为：月产 ≥1500 分钟且**利用率 ≥55–65%** 时自部署兑现。一期硬件（5060 Ti＋Spark×1）定位为**验收与自生产**，不摊产线成本、不承诺 SLA（Spark 实测 FastH3 768p≈340s/镜，单台月产能仅 150–400 分钟——量产 SLA 依赖二期托管弹性层）。

## 3. 需求

### 3.1 用户画像与典型场景

| 场景 | 用户 | 输入 | 期望 |
|---|---|---|---|
| S1 一句话成片 | 新手/试玩 | 「拍一个豪门弃妇逆袭」 | 全自动跑通，全程 ≤5 个拍板点，90 秒内拿到带水印样片＋一条真实试拍（评审修订：成片另计纳期，明示预期卡） |

## 4. 产品设计

### 4.1 体验宪法（六条）

① 用户说意图，剧组做专业；② 三层模式默认最简（一键成片→图文改编→导演台）；③ 决策点最小化（每集 4 个必答，其余「AI 已安排」）；④ 样片优先（最贵算力只花在被批准的样片之后）；⑤ 人话原则（§1.4 语言表）；⑥ 永不失控（自动可接管、手动有默认）。

### 4.2 概念模型

```
工作室 Studio（租户：席位/积分池/审计）
 └─ 系列 Series（IP 容器：风格圣经/演员表/场景库/音乐主题/世界观）
     └─ 集 Episode（竖屏 60–120s ×N；计费单元）
         └─ 场次 Scene（戏剧单元；mood 标签→配乐/调色分段）
             └─ 镜头 Shot（生产与计费原子：…→分镜图→成片段）
资产系统（挂 Series 跨集复用）：角色卡 · 场景卡 · 道具卡 · 风格卡 · 参考图四槽位
```

### 4.3 八阶段流水线与锁定门

| # | 阶段 | 必答点 | 锁定物 | 回滚影响 |
|---|---|---|---|---|
| 1 | 立项 | 大纲确认 | 系列圣经 | 全部下游 |
| 2 | 剧本 | 策划案卡 | 场次结构 | 场次/镜头重排，下游标 stale |
| 3 | 选角定妆 | **演员表逐人锁定** | 定妆照+角色卡 | 该角色全部镜头重出 **（2026-11-21 试妆试镜修订：锁定物升级为「初始图 refImage 确认＋C2S 试妆试镜拍板固化 viewRefs 多角度帧库」——人是本体背景只是壳，人脸五官/体态/眼神/表情高保真，分镜与拍摄首帧从帧库继承身份）** |
| 4 | 美术 | （默认过） | 风格圣经+定场照 | 全局重出（最高成本回滚，强警示） |
| 5 | 分镜 | **样片确认** | 镜头表 | 重排分镜图 |
| 6 | 关键帧 | 评分门自动＋**人审门（工作室档默认开，自动档可关）** | 分镜图锁定 | 该镜重拍 |
| 7 | 拍摄 | **预算报价确认** | take 择优锁定 | 重排合成 |
| 8 | 后期 | **验收** | 成片交付 | — |

铁律：先镜头表后生成；先粗剪后精做；**先锁画面后配乐**；批量必先报价。

### 4.4 决策点地图

每集 4 个必答卡：策划案 → 演员表 → 样片（开机）→ 验收；预算卡按触发出现。其余全部「AI 已安排」（可见可改可不管），深挖在导演台。

### 4.5 核心体验机制

- **AI 制片组**：八阶段拟人化为剧组角色（编剧/选角导演/美术指导/分镜师/音乐监制/摄制组/后期/制片主任），是平台内置 persona 包（ADR-003）；
- **样片粗剪**：分镜图+TTS+配乐的近零成本粗剪，确认后才「开机」；样片播放器明示「非正式画面」并附一条真实试拍样（校准预期）；
- **反馈翻译层**：重拍原因 chips（脸不像/动作不对/景别不对/节奏太慢/声音不对/太贵了）→ 系统映射为参考加强/运动重写/镜头表调整/换音色/降档路由；
- **进度与预期**：批量前「预计 18 分钟 · 约 ¥15 · 拍 16 镜」，进行中实时消耗，超 20% 暂停；
- **首跑体验（评审修订）**：新账号预载半成品模板项目（含**预生成**成片样例，成本收敛到一份共享资产）→90 秒内出**带水印样片＋一条真实单镜试拍**，正式成片明示纳期预期卡；先给结果再教流程（原「90 秒成片」与单镜 i2v 1–5 分钟物理时延矛盾，叙事降级）；
- **移动审片（评审修订）**：红果式竖屏逐镜；**上滑＝下一镜（保留消费语义）**，通过/重拍为底部大按钮＋确认（弹预计成本/时长＋原因 chips）；支持撤销、批量待审篮、帧级批注、@同事（微信服务通知触达）、弱网预载。

### 4.6 界面信息架构

**双表面**：创作驾驶（对话卡片流，新手/微调）× 工作台（故事板网格/详情抽屉/时间线/看板，专业）——同一项目数据，随时互跳。

关键界面：首页（输入框+四入口+模板流+项目进度）｜ 提案卡流（策划案/演员表墙/样片卡/审片卡）｜ 故事板网格（场次树+镜头卡片+拖拽+预算条+自动档路由条）｜ 台词本（逐句编辑+试听）｜ 时间线（三轨轻量）｜ 移动审片。

线框与文案规范全量见分册 [U] §5。

### 5.2 端侧（ADR-002 已决）

- **产品身份铁律**：剧场 = 独立 SaaS（自有 URL/账号/计费），**裸浏览器全功能可用**；宿主是渠道不是依赖；
- 技术栈：React + Vite、TanStack Query、**pragmatic-drag-and-drop（或 vendor pin dnd-kit 6.3.1——上游已停更）**（分镜拖拽）、自研轻量三轨时间线、原生 `<video>`、Sentry + feature flags、**Playwright 双 lane 冒烟（裸浏览器全功能的验收证据）**；
- **第三方宿主接入契约（v0.1 预留，商用期按需启用，P0/P1 不实现）**：deep link + **一次性 code（TTL 60s，含签名/PKCE/原子燃烧加固）换会话** + postMessage 事件桥（ready/export/theme）；异常降级「浏览器打开」；**剧场为完全独立产品，对任何宿主零依赖、零对齐义务**；
- **可移植性红线**：宿主零依赖（桥只做增强）、桥协议统一 postMessage（禁注入式 bridge）、手势纯 Pointer Events、上传下载标准 Web 能力。

### 5.3 服务拆分（职责见分册 [U] §6.1–6.2）

**一期生图选型（发起人确认＋2026-11-20 专项调研核实）**：
- **5060 Ti＝qwen-image-2.1-turbo-Q5_K_M**（unsloth 出品 5.39GB，8 步/CFG=1，现成资产属实）——同族 Q4_K_M 档含 TE+VAE 官方实测 9.1GB VRAM，Q5_K_M 推算约 10.5–11.5GB（调测期本机核实；2048² 档需 offload/Low-VRAM 模式）。**⚠ 许可：Qwen-Image-2.1/2.1-Turbo 均为 Qwen Research License（非 Apache）**——一期内测/自生产可用，**商用前法务审条款或切换 Apache 系**；
- **DGX Spark＝MiniMax-H3-Image（成立）**：H3 视频模型本体**无 T2I**（图像仅为输入条件；H3-Regenerate-2K 是 2K 视频重生成模块，不能生图），但官方 2026-11-03 发布**同家族独立开放权重 MiniMax-H3-Image**（33.1B DiT／6 步蒸馏／原生最佳 ~16MP，T2I+编辑统一 checkpoint；SGLang/vLLM-Omni/diffusers/ComfyUI 官方模板齐备）。**SGLang 官方 DGX Spark（GB10 128GB）实测：2K T2I 约 16.2s/图，MXFP8+FP8-attention 档约 11.0s/图**；建议常驻服务摊薄数分钟级冷启动；轻量替代 unsloth GGUF（DiT UD-Q4_K_XL 13.6GB＋TE Q4_K_M 18.2GB≈34GB，Spark 速度未实测）。**DGX 量化优先级（发起人确认，全局适用）：nvfp4 首选 → int8 次选 → 两者皆无才用 MXFP8+FP8 档**（兜底档须书面理由＋审计留痕，UI 规范 §11.2 已 UI 化：规则外档位不可达）——H3-Image 主 DiT 暂未见官方 NVFP4/int8 发布，故暂落 SGLang MXFP8+FP8 实测档；**跟踪官方/社区 NVFP4、int8 发布（unsloth 等），出现即切换并重跑定档回归**。**许可＝MiniMax-H3-Image 社区协议**：中国大陆可用（排除 EU/UK/US/KR）、**年营收 >$1M 或对外提供托管需另行书面授权**、商用 UI 须显著标注「MiniMax-H3-Image」；
- **Apache 兜底**（对外分发/私有化/商用免审场景）：Z-Image-Turbo（6B/8 步，官方称 16GB 消费卡可跑）或 Qwen-Image 原版/2512（Apache）——**注意「Qwen-Image Apache」仅限原版/2509/2511/2512 等，不含 2.1 系列**；
- **配乐 · 5060 Ti＝ACE-Step 1.5（MIT，发起人 2026-11-20 裁决一期标准版）**：情绪标签→配段落映射，每场 2–3 候选（30–60s）试听择优；**备选 Stable Audio Open（社区协议，商用条款 W1 核证后才可启用）**；产物带**许可双标记**（模型协议＋产物使用权），字段为空＝交付预检拦截；带唱/主题曲（YuE 级链路）＝二期 MusicAdapter 槽位。注：**L1 LLM 调用点维持 6 个（「音乐 mood」本在其内，ADR-003 §1）；配乐生成本体是 DAG 新增 worker 节点（生乐模型调用，非 LLM）**。
**模型准入白名单（许可逐仓核验）**：商用链路只走 Apache/MIT——Wan 2.x、**Qwen-Image(-Edit)（Apache 限定原版/2509/2511/2512 等；⚠ 2.1/2.1-Turbo＝Qwen Research License 非 Apache，仅一期内测/调测，商用前法务审或换 Apache 系）**、Z-Image(-Turbo)、ACE-Step 1.5、CosyVoice2；门槛监控——LTX-2.x（<$10M 全免含商用/≥$10M 购授权/禁蒸馏他模）、MiniMax-H3（>$20M＋**UI 显著标注**＋**排除 EU/UK/KR/US**＋托管防滥用＋禁训练他模）、**MiniMax-H3-Image（Spark 生图主力：大陆可用＋排除 EU/UK/US/KR＋年营收 >$1M 或对外托管需书面＋UI 标注）**、Hunyuan（MAU>1 亿＋排除 EU/UK/KR）；**禁入商用链路**——FLUX.1-dev/Kontext 全系、F5-TTS、MiniMax M2.7 开源权重、IndexTTS-2（license 未核）、CogVideoX（需注册＋月访问 ≤100 万）、LatentSync（两处 license 不一致，以包内文本留证）。

**生产化清单**：worker watchdog 与幂等重入（**OOM 铁律：同参数不重试、降档梯子、OOM 后强制重启进程**）、模板锁定一期＝镜像 digest＋nightly 冒烟（CI 回归基准随二期于 Spark/托管建立）、节点白名单+Manager 不暴露、8188 不出内网、产物 sidecar（seed/参数/版本/成本）。

### 5.5 智能体平台（ADR-003 已决）

- **三层智能体**：L1 剧组七角色（DAG 内函数式结构化调用+机检，无循环）+ 制片主任（确定性编排）；L2 对话副驾驶（**一期必上，发起人 2026-11-20 裁决；loop + tool-use，昂贵动作必经必答门；runtime 双模式：已部署 DSH 实例承载·默认／自建同契约兜底，ADR-003 D6/D7**）；L3 自定义助手（persona×skill）；
- **workflow-first 纪律**：agent 不自主点火昂贵动作；persona 不可豁免审批；
- **theater-mcp 工具面自持且 P0 定义**：既是 L2 工具面，也是 DSH 等外部智能体的接入面——**任何 harness 可插，不被绑定**；
- **Persona**：声明式版本化包（身份/语气/禁区/风格偏好/工具白名单/单次成本上限/记忆范围）；
- **技能**：声明式包（模板+工具链+机检+示例），积累三通道（采用 diff 沉淀候选/采纳率训练偏好画像/重复序列提议宏配方），采纳率驱动新陈代谢，候选→工作室→市场（P3）；
- **DSH（DeepSeek Harness）判定（发起人 2026-11-20 裁决修订，ADR-003 D6/D7 为准）**：LLM 通道 ✓（DeepSeek 主力复用）；**✓ 承载 L2 会话 runtime（模式 A 默认）**——形态问题已由「每会话一个 DSH 沙箱实例池＋`AgentRuntimeAdapter` 契约＋服务端终裁」解掉，准入走 **§5.4 六条清单（W1 headless 入口前置核验为唯一外部依赖风险，不可用则守护进程桥接 fallback）**；✗ 保留项：其**自带 shell/文件/代码工具整体禁用**、不进服务端治理面。**架构语义继续作自建 blueprint（模式 B）**：日志即真相→append-only 事件表、composer 审批→必答门、skills 目录→技能注册表、trajectory→观测 trace、compaction→长会话压缩。**作为外部智能体客户端＝P2 试点**（一期只做接口契约文档化，不接入——与 ADR-003 §7/FR-1210 期别一致）。

### 5.6 数据模型（核心）

```sql
series(id, studio_id, title, logline, aspect '9:16', platform_spec jsonb, style_bible jsonb, lore jsonb, version)
element_character(id, series_id, name, appearance_locked text, outfit, voice_card jsonb,
    anchor_asset_id, turnaround_asset_ids[], lora_model_id, face_embedding vector,
    embedding_model, embedding_version, style_domain '2d|real|hybrid',
    similarity_threshold real（去默认值，走 style_domain×model_route×embedding_version 标定表；
      2D 档用 DINOv2/CLIP 主体级比对）, status)
scene(id, episode_id, title, synopsis, mood_tags[], seq)
shot(id, scene_id, slug, cast_ids[], location_id, shot_size, camera_motion, duration_sec,
    dialogue_id, first_frame_prompt, first_frame_asset_id, end_frame_asset_id,
    pick_take_id, status, cost_accumulated, consistency_score,
    version bigint(乐观锁), stale bool, stale_reason, source_version_snapshot jsonb)
take(id, shot_id, asset_id, model_route, seed, gen_params jsonb, similarity_score, cost,
    state candidate|approved|rejected|superseded, origin user|auto_gate|auto_retry,
    picked 唯一性用 partial unique index ON take(shot_id) WHERE picked)
job(id, studio_id, shot_id|episode_id|scene_id, kind kf|mod|sim|tts|video|bgm|compose|export,
    state, depends_on[], worker_type, initiated_by user|system,
    payload jsonb, attempts, cost_estimate,
    idempotency_key, UNIQUE(studio_id, kind, idempotency_key),
    partial unique index WHERE state IN (queued,running) 防活跃重复)
billing_event(id, studio_id, job_id, attempt, meter gpu_sec|api_call|llm_token|storage_gb|cdn_gb,
    quantity, unit_cost, direction charge|refund, status accrued|settled|reversed, wallet credit|cash)
asset(id, studio_id, kind, uri, checksum, source_asset_ids[], status active|tombstone)
asset_ref(asset_id, referrer_type, referrer_id)——lineage 计数唯一事实源（删除保护/voice_card 样本登记）
wallet_txn(双分录钱包——「幂等不重复扣费」的对账不变量载体，配 property-based 对账测试)
approval(agent_run 昂贵动作：action_digest+实体版本向量+CAS 令牌+TTL 30min+单 pending)
locked_cut(episode 锁定剪辑版本快照——TTS retiming/配乐对齐依据)
persona / skill / agent_def / agent_run / preference_profile（§3.2 M12 详规见 ADR-003 §6）
```

**状态机**：Shot：draft→keyframeReady→keyframeLocked→generating→clipReady→clipLocked→composed→delivered；任一步 failed→重试/升人工；上游锁定物变更→stale 重开。Episode：outlining→scripting→casting→arting→boarding→kf_batch→gen_batch→composing→delivered。

**单镜头 DAG**：`kf(生图)→mod(机审)→sim(一致性门)→kf.lock→tts(台词)→video(i2v)→mod→take→pick→compose→export`，镜头间并行、集级批量编排、断点续跑、幂等计费。

### 6.1 合规义务清单（境内上线最小集，详版见分册 [P] §7）

① **底座与备案（评审纠偏）**：不存在「属地登记」豁免通道——调用已备案底座仅简化备案材料，**不豁免应用侧义务**。一期（商业化之前＝邀请制内测＋自生产，不向公众提供生成服务）以邀请制内测为合规边界；二期公测开放注册前完成**生成式 AI 服务备案（属地报送）＋算法备案（涉深度合成）＋安全评估（舆论属性自评）**，按 **6 个月**预留；经营性 SaaS 另需**增值电信许可（经营性 ICP/EDI，2–4 个月）**；B 端采购事实门槛**等保三级**（1–3 个月）同步排期；② 显式标识（GB 45438-2025：视频起始画面＋播放周边显著提示，导出必带；**该强制国标全文不免费公开，上线前购原文做字段级符合性测试报告**）；③ 隐式标识（元数据+水印，不可去除）；④ 机审+人工复审+处置留痕 ≥6 个月；⑤ 实名认证（**二期公测随备案启动**）+协议（含去显式标识的用户义务条款，并依法**留存获得无标识内容的对象信息日志 ≥6 个月**）；⑥ 舆论属性功能上线前安全评估（换脸/数字人类不做）；⑦ ICP 备案与素材授权台账；⑧ **持续合规义务日历**：备案→年度评估→功能变更重评→报告，每项 owner/日期/证据物；留存五类化（prompt、产物原件、审核记录、处置记录、实名与协议凭证）可按用户/时间/内容 ID 检索，调证响应 ≤24h；被举报处置 SLA＋向主管部门报告（标识办法第十四条）。
执法背景：网信部门 2025-11-25 已集中查处一批未落实 AI 生成内容标识的 App（约谈/责令限期改正/下架下线，cac.gov.cn 通报）——**合规工程是 B 端采购前提**。（评审注：原「处罚 200+ 起/单笔超 500 万」查无官方出处，已删）

### 6.2 内容安全流水线

prompt 机审 → 产物抽帧机审（0.02–0.25 元/分钟）→ 人工复审队列 → 违法内容处置与再训练义务；prompt 黑名单（名人/IP 角色/真人换脸）。

### 6.3 平台安全

### 7.3 团队建议

P0：1 全栈（产品链路）+1 平台（自部署 worker/编排/网关），产品设计由发起人兼任（**批 1 人则 P0 范围砍半而非延期**）；P1 增 1 前端 + 0.5 运营——评审容量测算：0.5 运营健康服务上限 6–8 家（复审不外包前提），**二期复审走云厂商 BPO（¥2–6k/月入预算）＋客户分层**，冲 15 家以上须 +1 名专职客户成功；P2 增推理工程 1 人 + 后端 1 人。**合规/法务外部顾问**自 P1 起介入（备案/增值电信许可/等保节点决策）。
