## 3. 全局交互模式（所有界面共用，先定义再进界面）

### 3.1 任务反馈五态（组件 `<TaskChip>`）
`排队中(灰) → 拍摄中(蓝·呼吸+已用¥) → 完成(绿✓) → 需重做(黄↻, stale 说「需重做」) → 失败(红!)` —— 失败态必附**下一步动词**（重试/换方案/找人看），禁止裸报错。全部状态以 job 账本轮询/SSE 双通道刷新（ADR-002 §7），断连时右上角出现「网络重试中」灰条而非弹错。

### 3.2 进度与预期（永不黑盒）
- 任何批量动作前必出**预估卡**：「预计 X 分钟 · 约 ¥Y · 拍 N 镜」＋难度标签＋（有则）同类历史；
- 进行中：全局顶部进度胶囊＋页内明细；**系统发起的自动重试显示「自动补拍中（免费）」且不计时费**；
- 超预算 20%：任务挂起→预算卡弹出（继续/降级/停），停留时长计入决策点统计。

### 3.3 卡片流（`<CardStream>`，创作驾驶主组件）
- 时间正序、卡片类型见 §5；新卡从底部滑入＋顶部胶囊提示「制片组有新东西给你看」；
- 必答卡未处理时置顶吸顶＋首页红点；**卡片按钮只有两态：主行动一个、次行动≤2 个**（其余收进 ⋯ 菜单）；
- 每张卡右上角 `ⓘ` 展开「谁做的/用了多久/花了多少」——举证三件套的可见面。

### 3.4 确认与审批（昂贵动作统一组件 `<ConfirmSheet>`）
开机/批量重拍/删除资产/解锁全局要素 → 底部抽屉：动作摘要＋预计成本/时长＋**「上下文已变」CAS 失效态**（数据版本变了→置灰按钮＋「重新预览」）＋倒计时不设计（不催用户）。

### 3.5 全局空/错/骨架规范
- 骨架屏：卡流用三张灰卡轮廓；图片位用品牌色 8% 底＋ shimmer；
- 空态必带「下一步」主按钮（如资产库空＝「去定妆」），禁止纯插画无行动；
- 错误分级：toast（轻，3s）→ 内联红条（中，附动词）→ 全局横幅（重：worker 掉线/队列积压，运维可见，用户侧文案「拍摄队列入库排队中，不影响你继续编辑」）；
- 404/无权限统一页：说明＋返回。

### 3.6 键盘与快捷（桌面）
`Enter` 卡片主行动 · `⌘/Ctrl+Enter` 确认 · `Esc` 关抽屉 · `Space` 播放/暂停（预览层） · `⌘K` 命令面板（一期仅：跳界面/搜项目）。

### 3.7 移动壳（H5 全局，A1 交付，所有 H5 界面继承）
- **底部 tab**：创作（卡流）／项目（树+资产）／拍摄（进度墙）／我的（成本+设置）——主导航一手可达；生产界面动作区一律放**拇指热区**（屏幕下 1/3），主行动按钮居右下；
- **返回策略**：Android 系统返回＝先关抽屉→再退页面层级（永不直接退出项目）；iOS 左上返回＋右滑手势（右滑只承担「返回」，与 S11 审片上滑手势互不冲突）；
- **长按菜单**：桌面所有 hover 态操作在 H5 一律有长按 sheet 等价物，无例外；
- **软键盘**：输入框自动顶起不被键盘遮；成本/秒数类输入用数字键盘；键盘弹起时底部主按钮临时上移；
- **safe-area**：`viewport-fit=cover`＋上下安全区适配；底部 tab 与底部抽屉避开 Home 条；
- **弱网**：图片默认低码率＋懒加载；视频预览 540p 先行、点按切高清；全部写操作带幂等键可安全重试；断网提交入本地待发队列，恢复后按序补发；
- **上传**：资产库/人工注入支持相册与相机直取（`accept`＋`capture`），选图后压缩再传；
- **触达**：PWA「添加到主屏」引导（一次性）；推送被环境限制时（微信内置浏览器）落短信/IM 通知＋落地页深链；
- **双端同步**：H5 完成的操作（批复/择优/重拍）经 SSE 实时反映到桌面卡流与工作台，双向一致（V4 覆盖用例）。

## 4. S1/S2 进门与首页

**S1 登录/邀请**：手机号验证码（一期主路径）＋邀请码字段（内测）；无邀请码→「申请内测」留资卡。成功→首次进 S16，非首次→S2。失败内联提示＋重发 60s 倒计时。

**S2 首页四态**：
1. 无项目：输入框吸顶（「一句话、一段故事、或整篇小说，都行…」＋「开拍 ▶」），下方四入口磁贴＋模板流（每模板卡＝成片 demo 自动静音播 3s）；
2. 有项目：「继续」行前置（缩略图＋进度「E01 拍摄中 12/16 · 已用 ¥23/50」）；
3. 有未批必答卡：顶部横幅「演员表等你拍板」（点击直达该卡，**这就是 90 秒回访的钩子**）；
4. worker 异常期：入口可用，批量按钮置灰＋横幅（§3.5 用户侧文案）。
**H5 形态**：四态同构（首页即「创作」tab 首屏）：输入框吸底拇指热区、模板流横向卡片滑流（静音自动播仅 Wi-Fi，省流量）、进度行改双列卡。**手机上「说一句就能开拍」是 P0 体验，不是桌面残影**。
埋点：入口点击分布、模板→创建转化、必答横幅点击率（双端分端记 `platform` 维度）。

### 5.2 副驾常驻驾驶栏结构（S18 桌面/H5 同构，发起人 2026-11-20 裁决新增）

**定位**：辅助驾驶席——不是隐藏式聊天窗。桌面右侧常驻（折叠只是收起，会话/任务状态不丢，一键再展开）；H5 为底栏中央一级 tab。**栏内三视图＋底常驻件**：
1. **对话**：消息流（组员 persona 署名＋runtime 徽标「DSH 实例 · 模式A」）、工具调用**时间线卡**（工具名·状态推进 排队→执行中→完成/失败·费用·时长·trace 链接进 AgentRun）、流式中可「停止」、历史会话条（当前集会话＋新建）；
2. **任务**：助手代发起的后台任务列表（TaskChip 五态＋下一步动词＋「免费补拍」角标复用），点击跳对应界面（S8/S10）——**代跑可见**是信任的前提；
3. **审批**：待必答门事项收件箱（动作摘要＋预估＋CAS 上下文版本；确认＝`T.confirm`，驳回留痕）——**审批不藏在对话流里**，有红点计数；

纪律：常驻不改变「卡流是唯一主写面」——副驾承接查询与一句话代办；预算仪表只读；H5 中央 tab 触达即全屏，输入区遵守 §3.7 拇指热区与软键盘策略。一期同时**静默采数**（adopt_diff/rerun chips/asset_regen，§13）喂养二期的技能候选池与偏好画像——积累在二期「显形」为：副驾懂你的词汇黑名单、主动配方建议卡、越用越准的预估卡。

## 11.2 模型与运行时配置面（S15 内「模型与运行时」页签，内部，B7＋B10 只读态）

**四块＋一灰置区**：
1. **段位×驱动模型注册表**：一行一段位——生图·5060 Ti（qwen-image-2.1-turbo-Q5_K_M · **W-B 无头 ComfyUI，ADR-001 §3 端点定案**）／生图·DGX Spark（MiniMax-H3-Image · SGLang）／视频·5060 Ti（LTX-2.5 distilled GGUF UD-Q4_K_XL · W-B）／视频·DGX Spark（FastH3 NVFP4）／**配乐·5060 Ti（ACE-Step · W-M 无头生乐服务，发起人 2026-11-20 标准版裁决；备选 Stable Audio Open 许可核证中）**／LLM（DeepSeek 峰谷调度）。每行：模型名＋版本 pin、量化档、自部署端点地址＋健康状态点（心跳**对齐 ADR-001 §4 生成侧失败梯子＋ADR-003 §1 LLM 四层策略**，终审修正引用）、「探测」一键巡检。改端点/换模型＝`<ConfirmSheet>` 留痕（操作者/时间/前值）。

3. **密钥与峰谷**：一期唯一 API 侧外部依赖＝DeepSeek——密钥打码显示、仅可重填不可回显、「验证」按钮做一发试调用回延迟/余额、峰谷调度开关＋谷段窗口展示（LLM 批量调用移谷段）。自部署端点无密钥（自部署纪律注记）。
