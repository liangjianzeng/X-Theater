> 版本：v1.2（2026-11-20；终审修正轮：署名面/手势/章节引用/语言表 worker 行/剧组 persona 口径）
> 定位：**全新独立模块，不受现有实现约束。算力策略（2026-11-20 修订）：一期（商业化之前）以平台自部署模型为执行主体**——5060 Ti 开发调试/前期调测＋DGX Spark 验收与自生产（生图 qwen-image-2.1-turbo、视频 LTX-2.5 distilled / FastH3 nvfp4 直调）；**商业 API（可灵/即梦/Vidu/海螺等已备案底座）与托管弹性是二期商用运营策略**（平台商用化最后接入项），一期只做 UI 槽位与接口（模型网关 ProviderAdapter/worker_type）预留；LLM API（DeepSeek）不在此列，属一期主用通道。

## 1. 产品形态决策

| 决策 | 结论 | 理由 |
|---|---|---|
| 算力 | **一期自部署为主**（5060 Ti 开发调试＋DGX Spark 验收/自生产）；商业 API/托管弹性＝二期商用运营策略，仅契约与 UI 槽位预留 | 集中力量做平台自有能力；已备案底座合规轻路径、BYOK/积分双轨（§6.4）与弹性按量留待二期商业化启用；一期不承诺 SLA（验收/自生产语义） |

| 新建 or 改造 | **全新代码库**（仅复用 mode-plan v2.2 的数据模型与合规设计；不复用任何既有产品代码） | 独立新产品线，不背旧实现包袱 |
| 核心隐喻 | **用户是「出品人」，AI 是「制片组」** | 用户不学技术，只做甲方拍板：看提案、定演员、批样片、验收成片 |

## 2. 体验宪法（六条，所有设计决策的裁判）

1. **用户说意图，剧组做专业**——用户只表达「拍什么/什么感觉/哪里不对」，全部技术动作（提示词、模型路由、一致性参数）由系统承担；
2. **三层模式，默认最简**——一句话成片（全自动）→ 图文改编（半自动）→ 导演台（全控），用户永远可以往上走，但从不被迫；
3. **决策点最小化**——每集 4 必答＋预算触发＝4–5 张决策卡（与总文档 §4.4 同径），其余一律「AI 已安排」（可见、可改、可不管）；
4. **样片优先**——最贵的视频算力只花在被批准的样片之后；样片（分镜图+配音+配乐粗剪）成本近零；
5. **人话原则**——界面禁止出现 prompt/seed/i2v/LoRA/节点等词（§7 语言表）；一切状态翻译成制片语言；
6. **永不失控**——任何自动化都可视化、可暂停、可手动接管；任何手动操作都有 AI 默认值兜底。

## 3. 核心体验机制

### 3.1 AI 制片组（拟人化的流水线）

> 七位组员不是文案——是平台内置的**智能体 persona 包**（人格/工具白名单/技能绑定），工程实体化见 [ADR-003](theater-agent-platform-adr.md)。

八个技术阶段全部翻译成「剧组分工」，用户面对的是一群角色而不是一条状态机：

| 剧组角色 | 对应技术阶段 | 用户看到的 | 必答点 |
|---|---|---|---|
| 🖋 编剧 | 立项→剧本→场次→台词表 | 「剧本策划案」卡片（梗概/幕结构/台词本） | ✅ 确认故事方向 |
| 🎭 选角导演 | 角色卡→定妆照→三视图 | 「演员表」：定妆照墙，点人可换 | ✅ 定妆确认（一致性根基，**唯一强制逐人确认**） |
| 🎨 美术指导 | 风格圣经→场景定场→道具 | 「美术方案」：3 张场景图+风格 chips | ⚪ 默认采纳 |
| 🎬 分镜师 | 镜头表→分镜图 | 「分镜脚本」条（可拖拽/逐格换图） | ✅ 样片确认（节奏拍板） |
| 🎵 音乐监制 | 配乐 cue/TTS 配音 | 样片里直接能听 | ⚪ 默认采纳 |
| 🎥 摄制组 | 首帧→视频生成→口型 | 「拍摄中 12/16 镜」进度 | — |
| ✂️ 后期 | 合成/转场/字幕/混音/标识 | 「成片」+ 审片卡 | ✅ 验收 |
| 📋 制片主任 | 编排/预算/路由 | 「预算与进度」侧栏（始终可见） | ✅ 批量前报价确认 |

### 3.2 决策点地图（每集 4 个必答，其余自动）

| 阶段 | 系统自动做（不可见） | 必答卡 | 可深挖（导演台） |
|---|---|---|---|
| 编剧 | 世界观补全、场次划分、台词节奏化 | 剧本策划案 | 台词本逐句编辑 |
| 选角 | 4 候选定妆/人、音色匹配 | 演员表（逐人锁定） | 换参考图、改外貌字段 |
| 美术 | 风格推导、场景图×3/场 | （默认过） | 风格圣经编辑、定场重出 |
| 分镜 | 镜头表生成、机位时长分配；关键帧评分门＋**人审门（工作室档默认开，自动档可关）** | 样片粗剪 | 分镜条拖拽、逐格换图、改镜别 |
| 拍摄 | 自部署路由（一期单路＋档位）、一致性自动重试 ≤2（**系统发起不计费并明示**） | 预算报价卡（难度标签＋历史 takes 依据） | 自部署档位（分辨率/步数/量化档）；指定模型/seed 随二期（「复刻上一次」表述） |
| 后期 | 转场、字幕、混音、合规标识 | 审片卡 | 时间线精修、逐镜重拍 |

### 3.3 样片粗剪（体验的枢纽）

全产品最重要的一个交互物：**正式拍摄前，先用近零成本合成一条「样片」**——分镜图按序播放 + 台词 TTS + 配乐 + 简单转场，竖屏 mp4。
- 对用户：第一次「看见自己的剧」，拍板的是节奏和故事，不是技术；
- 对成本：样片 = N 张图 + TTS + FFmpeg（<2 元），拦住了 N 段视频（30–90 元）的浪费——**这是 AI 制片 vs 用户手动工具的本质效率差**；
- 确认动作就叫「**开机**」——情感化命名降低理解成本。

### 3.4 反馈翻译层（用户的抱怨 = 系统的参数）

用户不懂机制，但一定会说「不对」。每次重拍/换图都给 reason chips，系统翻译成技术修复：

| 用户点选 | 系统实际做 |
|---|---|
| 「脸不像/人变了」 | **先出诊断卡**（当前像不像分/疑似成因/修复方案与各自预计费用），禁止静默重扣费；修复＝换定妆照角度/改写外貌锁定字段/换生成路线（原「自动提阈值重出」为静默重扣费陷阱，评审修正）；**同镜同因重拍 ≥2 次强制升人工** |
| 「动作不对」 | 重写该镜运动描述（LLM 改写），换模型重生成 |
| 「景别/构图不对」 | 改分镜图（图像编辑 API 局部重绘），再重拍 |
| 「节奏太慢/太跳」 | 进入分镜条：合并/拆分镜头、调时长（改的是镜头表，不是视频） |
| 「声音不对」 | 换音色卡或调情绪参数重 TTS |
| 「太贵了」 | 降模型档位路由（高清→标准），或减少重拍次数 |

### 3.5 进度与预期（永不黑盒）

任何批量动作前必显示：**「预计 18 分钟 · 约 ¥15 · 拍 16 镜」**；进行中显示「拍摄中 7/16 · 已用 ¥8.3」；超预算 20% 自动暂停等确认。所有等待态给进度条+下一步预告，绝不裸转圈。

### 3.6 新手首跑体验（评审修订：叙事从「90 秒成片」降级为「样片首跑」）

新账号进首页 → 默认载入一个半成品模板项目（故事已写好、演员已定妆，**含预生成的成片样例**——成本收敛到一份共享资产）→ 90 秒内看到带水印样片＋**一条真实单镜试拍**（校准预期）→ 点「开机」后正式成片明示纳期预期卡（单镜 i2v 在自部署档为分钟级物理时延，「90 秒成片」不承诺）。**先给结果，再教流程**；教学永远发生在用户刚做完对应动作之后（情境提示卡，一次性）。

## 4. 资产系统（剧组物料）

- **角色卡**：姓名/外貌锁定字段/服装 + 定妆照（正面锚点）+ 三视图 + 音色卡；状态：试镜中→已签约（锁定）；跨集复用；
- **场景卡**：描述/mood + 定场照×3（不同机位）；
- **道具卡**：描述+参考图（信物类关键道具）；
- **风格卡**：色板/光照/镜头感/负向词，全局生效；
- **参考图四槽位**（Vidu 模式）：人物槽/物品槽/场景槽/风格槽——上传自有素材（真人照片、商品图、竞品画风）直接入槽参与生成；
- **人工资产注入（P1，评审补）**：AI 搞不定的镜头可上传人工制作的视频/图片替代某 take 或分镜图并参与合成——标「人工物料」、不进像不像评分、正常计费（失败镜的人工兜底，产线与玩具的分界）；
- **IP 沉淀**：续拍第二集，演员表/场景/风格一键继承——「换平台=弃用全部资产」是我们最深的使用壁垒（对齐 v2.0 护城河）。

```
│ ⚡自部署档: 标准 · 高价值 · 夜间（用户侧唯一旋钮，模型/硬件名不进工作界面）│
│   · 夜间闲时队列   [更聪明的安排·商业化阶段开放→二期]  [改手动: 档位]  │
└────────────────────────────────────────────────────────────┘
```

### 5.5 台词本（Suno 式「生成前精修文本」）

全屏编辑器：左=场次/台词逐句列表（角色/内容/情绪/预计秒数），右=朗读试听（TTS 即点即听）。**这是视频生成前用户对文本的最后掌控点**——台词逐字影响口型与时长，必须让用户改到爽为止。

### 5.6 时间线（后期页）

三轨横向时间线（视频/音频/字幕），镜头块拖拽排序、转场块插入、字幕轨自动生成可改；导出预设：抖音/快手/红果/YouTube（竖屏 1080×1920 / 横屏 1920×1080 / 帧率/码率）。复杂度对标剪映、上限砍掉 90%——只做「AI 生成内容的组装」，不做通用剪辑。

### 5.7 移动审片（H5，红果式）

全屏竖屏逐镜播放（弱网先载低码率预载）；**上滑＝下一镜（保留红果消费语义，不兼提交动作）**；**通过/重拍为底部大按钮**——重拍先弹确认（预计成本/时长＋原因 chips）；支持撤销、**批量待审篮**（先看完再一次性提交）、长按评论与帧级批注、@同事（微信服务通知触达待审人）。制片人/导演在地铁上就能批完一集。

### 6.1 总体

```
 └──────┼──────────────────────────────────────┘
        │
```

### 6.2 关键设计

- **编排器**：每镜头一条持久化 DAG（分镜图→审核→一致性门→视频→审核→择优→合成），断点续跑、幂等计费、预算护栏——与 mode-plan v2.2 §4.3 同构，只是执行端从本地 GPU 换成自部署 worker／二期 API；
- **模型网关**：ProviderAdapter 统一抽象（各家 API 参数/回执格式不同）；自动档路由表按镜头类型分发（用户侧映射＝§5.4 档位底栏「标准/高价值/夜间」三件套）；失败降级链（主模型超时→备模型→通知）；每 job 记录供应商/耗时/花费，成本穿透到镜头；**自部署模型的后端形态（一期执行主体＝无头 ComfyUI worker（5060 Ti/Spark）＋ H3/FastVideo 直调毕业层；托管弹性与商业 API 为二期商业化层，均经 worker_type/ProviderAdapter 契约预留、ComfyUI 端点零暴露）已由 [ADR-001](theater-infer-backend-adr.md) 决策（2026-11-20 修订）**；
- **一致性服务**：定妆照 embedding 缓存 + 评分门（**阈值走 style_domain×model_route×embedding_version 标定表，无硬编码默认；2D 档用 DINOv2/CLIP 主体级比对**；相似度 <阈值自动换参考重拍 ≤2 次→升人工，系统发起不计费）+ **一期自部署图像编辑（qwen-image-2.1 系）做参考条件生成**；
- **合成集群**：云函数/容器 FFmpeg 池（样片、成片、转码、显式+隐式标识写入——标识在合成层强制，用户不可绕过，对齐 mode-plan v2.2 §7 合规）；
- **审核流水线**：prompt 机审→产物抽帧机审→人工复审队列→留痕 ≥6 个月。

### 6.3 多模型自动路由（**二期商业化能力**·自动档，用户无感；一期实跑下表「一期自部署档」列，多供应商列仅作二期路由表 schema/槽位预留）

| 镜头类型 | 一期自部署档 | 二期供应商档（预留） | 理由 |
|---|---|---|---|
| 台词/口型镜头 | 画外音+空镜+字幕策略规避（P0/P1） | 可灵口型 或 海螺+lip sync；H3 原生音频轨评估 | 台词是短剧核心，口型质量优先 |
| 大动作/打斗 | Spark FastH3（高价值）/LTX-2.5（标准） | Seedance / 可灵 2.5+ | 运动质量 |
| 转场/衔接 | LTX-2.5 FLF 档 | 首尾帧能力模型 | 连续性 |
| 氛围空镜 | 5060 Ti 最便宜档 | Vidu（最低价 720p） | 成本敏感 |
| 草稿/样片 | 5060 Ti 蒸馏快档 | 最便宜档 | 近零成本验证 |
导演台可改手动档逐镜指定（一期为档位指定）；路由表运营可配置（新模型上线即接入评测）；**夜间闲时队列**：非紧急批量排入 Spark/5060 Ti 闲时段换成本优势。

### 6.4 计费（**二期商业化解法**；一期影子记账不扣费，见 §8-P0-7）

双轨并行（聚合器行业已验证）：
- **平台积分**（默认）：用户充值积分，我们统一采购 API，赚工作流+批量折扣差价；
- **BYOK 自带 Key**（进阶档）：用户填自己的可灵/即梦 API Key，生成费用直付供应商，我们只收**工作流订阅费**（提案/一致性/资产库/编排/存储的价值）——零算力资金占用、API 价格战与我们无关；
- 每镜头成本透明穿透显示（一期用户面只出「这镜花了 ¥2.5」；**供应商/模型名仅二期 BYOK/导演台界面按 §7 豁免出现**），工作室客户极度看重。

## 8. 实现分期（全新代码库；一期自部署为主，2026-11-20 修订）

## 9. 风险（体验与架构视角）

| 风险 | 对策 |
|---|---|
| API 成本 15–90 元/分钟，毛利薄（**二期商业化后**） | 量产档内 API 混入率 ≤5–8% 硬约束；BYOK 双轨；自动档把 80% 产量压到自部署档；样片前置拦截浪费；闲时折扣 |
| 各家 API 规格/稳定性参差（二期） | ProviderAdapter + 降级链 + 评测基准集（每接入一家先跑内部 benchmark） |
| 台词口型质量不达标 | 台词镜头单独路由档；一期先做「台词+字幕」不出镜（画外音+空镜），口型随二期——避免 MVP 被最难问题卡死 |
| 用户对「样片≠成片」预期落差 | 样片播放器明示「非正式画面」；样片阶段就给一条真实视频试拍样（单镜 5s，让用户校准预期）；首跑预生成样例＋纳期卡 |
| 合规（标识/审核/备案） | 合成层强制标识；机审前置；**一期邀请制内测＋自生产为边界，公测前生成式 AI 服务备案＋算法备案＋安全评估＋增值电信许可＋等保就绪（无「属地登记」豁免，v2.0 §7 纠偏清单照用）** |
| **自部署吞吐瓶颈**（Spark 768p≈340s/镜、5060 Ti 单机） | 一期不承诺 SLA（验收/自生产语义）＋夜间闲时队列；二期托管弹性为 SLA 主力（公测 gate：≥2 节点/并发 ≥8） |
| **自部署量化档质量不达商用线** | 调测期量化档位对比＋盲评定档；一致性评测集回归；二期商业 API 质量档兜底 |
