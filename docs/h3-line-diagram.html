第 0 幕

起点：剧本 = 唯一结构化源头

业务场景 · 立项
编剧产出的不是文档而是 结构化 JSON：分场分镜表（画面描述/时长/在场角色/台词/档位）＋角色定义表（人设/外形锚点/服装锁/参考图）。全链所有环节都从这里透传，不再有二次解析。
业务层用户操作
POST /api/projects 建项目（影调/画比/音乐开关）　→　POST /api/episodes {title, brief, script}
编排层DAG 引擎
建集即派 c1plan 任务；引擎按 type × tier 路由 lane（tier=high ⇒ 全族走 imgspark·H3 线）； aireview 对 C1/C2/C4/C6 拍板卡自动多人格机检
产物层数据结构
script.scenes[]{name, mood, shots[]{desc, sec≤15s, cast[], dialogue, tier, width, height}}　script.cast[]{role, name, desc, anchor, wardrobe, refImage}
▼建集完成 → engine.enqueue("c1plan") → 进入故事策划
第 1 幕

C1 故事策划卡 ＋ H3 主视觉海报

业务场景 · 策划拍板
业务层C1 卡
用户看到：故事梗概 ＋ 人物表 ＋ 分场分镜表（每镜画面描述/时长/台词）→ accept（必答门①，决策+1）；reject → 重出 c1plan
编排层状态机
c1plan done → 卡流监听 onPlanDone 生成 C1 卡；accept 后 ensureScenesAndShots 把剧本物化成 state 场/镜（镜号 seq = 场×100＋镜）
模板层固化模板
h3-image-cast（transform 删 LoadImage 4/5/6 → 纯 t2i）768×1344 竖版海报　节点链：UNETLoader→MiniMaxH3ImageConditioning→ConditioningZeroOut→KSampler(6步 euler/simple cfg1)→VAEDecode→SaveImage
模型层权重
minimax_h3_image_pruned_int8_convrot 20.98G 生图 DiT　＋　qwen3vl_32b_nvfp4_awq 15.7G 文本/图像编码器　＋　minimax_h3_image_vae_fp16 1.17G　→ 实测 14.9s/张
产物层落盘
var/out/<jobId>_poster.png ＋ meta sidecar（prompt_id/权重清单/AI 标注）· 影子记账 20 分
▼C1 accept → 场/镜物化 → storyboard(壳任务) → 进入「初始定妆」
第 2 幕

初始定妆：确立「角色身份源」

业务场景 · 用户三入口确认制
身份从这里锁定：用户上传的原图就是定妆终稿（也可以让 H3 按提示词生成候选再挑）。此后所有环节（试镜、分镜、视频）都以这张图为身份根，不再自动随机生成新脸。
业务层C2 卡
每个角色三选一：① 上传原图 ② 提示词生成初始图 ③ 继承旧集定妆（跨轮沿用，脸不重掷）→ 卡上点「确认」
编排层REST API
① POST /api/episodes/:id/castref/upload?role=X（raw PNG/JPG ≤16MB，router 支持 raw body） ② POST …/castref/generate {role, prompt} → cast_init job ③ POST …/castref/confirm {role, file}
模板层生成入口
cast_init 走 h3-image-cast 纯 t2i：864×1536 精确 9:16（32 倍数）· 半身景别·面部清晰锐利；产物追加为该角色候选「AI 初始图」
模型层门控模型
confirm 时 facegate buffalo_l（insightface，:8195）做人脸存在性机检——no_face 拒绝确认；ArcFace embedding 即身份基准
产物层固化
var/assets/cast/<file>.png → 写入 cast.refImage；全员确认齐 → 自动派 screen_test（每角色 1 条，engine.activeOf 防重派）
▼全员 refImage 就位 → 自动派 screen_test（★ 本次调整核心幕）
第 3 幕 ★

试妆试镜（C2S）：一条视频锁死「脸＋体态」

业务场景 · 高保真身份采集
为什么用视频不用照片：一张定妆照只有一个角度；分镜需要的左右 3/4 侧脸、仰头、低头等姿态各有专属参考帧。用初始图直接作首帧生成一条多角度试镜视频，再逐帧打分挑帧——背景和道具只是壳，人脸五官、体态、眼神、表情才是要高保真的本体。
业务层C2S 卡
用户看：试镜视频 ＋ 7×2 抽帧网格 ＋ 逐帧分数/角度 ＋ 确认清单（五官脸型/身材体态/服装细节/多角度）→ 勾选拍板；不满意 → reject 附意见 note → 自动重出试镜
编排层screen_test job
lane 固定 imgspark；流程：ffmpeg cover 裁切初始图 → 上传 Spark → FL2VA 真跑 → 抽帧 → 逐帧打分 → onScreenTestDone 出 C2S 卡
模板层h3-fl2va-video
节点链：LoadImage(FIRST_FRAME)→MiniMaxH3ImageToVideo→SamplerCustomAdvanced(res_multistep)→VAEDecode+VAEDecodeAudio→CreateVideo(24fps)→SaveVideo
参数：736×1312（32 倍数等比裁切）· 124 帧 / 5.17s · turbo 4 步 · timeout 1500s · 动作提示词＝正面→左 3/4→右 3/4→仰头闭眼→回眸微笑（覆盖分镜所需头部角度）· 用户 note 追加尾部
模型层权重
minimax_h3_fl2va_pruned_int8 20.97G 首帧→声画 DiT　＋　fl2v_turbo_4step LoRA 1.96G（40+步→4步蒸馏）　＋　video VAE 5.21G ＋ audio VAE 0.61G（原生声画）　＋　qwen3vl_32b TE 15.7G
产物层抽帧＋固化
<jobId>_screentest.mp4 → ffmpeg select=not(mod(n,10)) 抽 ~13 张全分辨率候选 → 逐帧 facegate ArcFace 打分（yaw/pitch 角度标签）→ <jobId>_grid.png 7×2 缩略墙
accept C2S → score≥0.6 硬线过滤 → 拷贝 var/assets/cast/<role>/views/ → 固化 st.viewRefs[episodeId][role]（分镜的身份输入源）
▼viewRefs 固化 → 自动派 storyboard_char（分镜＝选角度帧＋换背景壳）
第 4 幕

角色分镜＝「选角度参考帧 ＋ 只换背景壳」

业务场景 · 保脸分镜
分镜不再重新画人：每一镜先解析出需要的头部角度，从试妆帧库选最匹配的参考帧，然后 H3-Image edit 只替换背景与环境——人（脸/五官/发型/体态/头部角度/服装）原封不动。
业务层分镜可见
分镜首帧逐格出现在 C2/C4 卡（带 refAngle/refT 溯源：用了哪条试镜帧、什么角度）；用户 reject → 重出
编排层storyboard_char job
逐镜：shotAngleNeed(镜desc＋角色anchor) 关键词解析（仰头/低头/左侧脸/右侧脸/正面）→ pickView(viewRefs) 选该角度最高分帧（缺角度→front→全局最高分兜底；旧集回退初始原图）；同图上传缓存不重传
模板层h3-image-edit
img2img：KSampler 的 latent ← 参考帧 VAE 编码（身份像素级保真）· 宽高＝原图 /16 对齐
提示词模板：「人物保持完全不变——脸、五官、发型、体态、头部角度与参考帧一致，服装：<wardrobe 锁>。只替换背景与环境为：<该镜描述>。单幅剧照，禁止分屏拼贴。实拍电影剧照质感，浅景深」
模型层门控闭环
H3-Image DiT 20.98G（edit 模式）＋ facegate inswapper_128：出图 → ArcFace 打分，<0.6 → /swap 换回锁定源脸再打分；每镜 2 次尝试，仍不过 → IDENTITY_GATE_FAIL 进自动补拍梯子
产物层分镜首帧
var/out/<jobId>_h3charN.png → onStoryboardCharDone 按 seq 绑 shotId → 回填 C2/C4 卡 → 即第 6 幕拍摄的首帧源
▼C3 演员表锁定 → C4 分镜确认 accept → 派 voice / music / compose(preview)
第 5 幕

配音 · 配乐 · 预览 · 预算

业务场景 · 声音资产与成本确认
业务层C9→C5→C6
每场音乐 3 候选 → C9 采用卡（reject=换一批；永不计决策数）→ C5 预览样片卡 → C6 预算开机卡（estimate_ver，CAS 防并发拍板）
编排层三条 lane 并行
voice（每场 1 job，场景过滤·诚实空结果）· music（每场 1 job，mood→候选）· compose(preview)；台词产物持久化 state.voice_lines（compose 断供保护）
模型层声音模型
CosyVoice2 :9880 台词→wav（角色→音色映射「女主→中文女」，TTS 前卸 ComfyUI 显存互斥）　·　ACE-Step 1.5 :8190 mood→45s BGM wav（MIT 许可·预检拦截演示位）
产物层声音资产
var/out/tts_*.wav（供第 8 幕对位混流）· music_*.wav（采用条入曲库带 license 快照）
▼C6 accept ＋ POST /shoot {ver} CAS 校验 → 逐镜派 video job
第 6 幕

开机拍摄：逐镜「原生声画」视频

业务场景 · 高价值档出片
业务层开机
预算确认后一键开机（支持 shotIds 局部重拍）；预算护栏：累计成本 > 预算×120% → 整集暂停
编排层模板二选一
逐镜查 C2 分镜图（按 shotId 绑定）：有首帧 → h3-fl2va（首帧锁构图与长相）；无首帧有定妆 → h3-ref2va（subject reference 保脸兜底）；两者皆无 → NO_SPARK_INPUT_ART 真错误不造假。拍摄前 ensureFree(base,8) 内存守卫
模板层IR 提示词引擎
h3ir（官方 Context-IR 规则化复刻）：buildFL2VA 三字段（integrated_multimodal_description / overall_soundscape / non_diegetic_music）· buildRef2VA 六段式（subject_definitions / summary / retention_analysis / detailed_description / …）· 台词以 <d>[中文]…</d> 内嵌 → 口型自动同步 · lengthFrames(sec)：max(124, sec×24) 对齐 17k+5 帧网格，上限 362 帧≈15s；可选 LLM 全英文重写（默认关）
模型层视频族权重
fl2va DiT 20.97G / ref2va DiT 20.97G ＋ turbo 4step LoRA ＋ video VAE 5.2G ＋ audio VAE 0.61G；res_multistep/simple · 768×1344 竖屏 · 同族常驻不互逐（跨族才 /free）· 实测 fl2va 286.5s / ref2va 260.4s 每镜
产物层take
var/out/<takeId>.mp4 画面动作＋对口型台词＋环境声一步到位 · 150 分/镜 · meta 带 IR/LLM/权重四元组
▼每镜 video done → 自动派 moderate 机审
第 7 幕

机审 · 复审 · 收官

业务场景 · 质量门
业务层C7/C8
机审 pass → 镜 ok；fail → 复审队列 ＋ C7 复审批复卡（每集唯一，新落审镜并入同一张）→ 批复通过 / shotIds 局部重拍 → 全部 ok 且无 pending 复审 → C8 收官卡
编排层moderate lane
verdict 规则机审（pass / fail_review）；失败补拍梯子：worker 抛错 → 系统免费重试 ≤2 次（共 3 跑）→ failed＋告警
产物层状态
shot.status: pending → moderating → ok / pending_review；全 ok 触发 maybeFinishShoot 出 C8
▼C8 accept → 导出 → compose(purpose=export, THEATER_COMPOSE_REAL=1)
第 8 幕

成片导出：FFmpeg 真合成

业务场景 · 交付
节点层合成流水线
① 片头字幕卡 2s（drawtext 黑底白字＋静音轨统一流）　② 逐镜 best take（显式 best 优先·新拍覆盖旧拍；音轨统一 aac 48k stereo，无音轨补 anullsrc）　③ concat 拼接
④ 台词对位：voice_lines 按剧本扁平镜序（seq=场×100＋镜）对齐时间轴 adelay 叠加——take 自带原生说话声的镜自动跳过，不双叠　⑤ 终混：BGM volume 0.18 ＋ 台词轨 amix(normalize=0)
模型层合成引擎
FFmpeg 6.0（runtime/bin·essentials，无 ffprobe 用 -i stderr 探测时长/音轨）
产物层✅ 最终成片
var/out/<episodeId>_final.mp4 · 720×1280 · 24fps · h264+aac · 内测水印 · meta（explicit/implicit 标记＋每场音乐许可快照）；真机交付实证 1:22.66 · 26.4MB

▶ 横切纪律（每一幕都受约束）

模板四元组锁定sha16 × ComfyUI commit × 节点 commit × 权重清单，manifest 校验不过即拒跑（COMFY_TMPL_DRIFT）
内存族常驻h3video / h3image 同族连续出片不卸载；跨族才 POST /free；ram_free<8G 才释放（Spark 统一内存纪律）
身份门控 0.6ArcFace ≥0.6 过审；不达标 swap 换回源脸复核；2 次重试仍不过 = 真错误进补拍梯子
失败补拍梯子worker 抛错 → 系统免费重试 ≤2 次（共 3 跑）→ failed＋告警；绝不静默回退造假
预算护栏＋CAS成本>预算×120% 整集暂停；卡 ver / estimate_ver 不符 → 409 STALE 防并发拍板
aireview 拍板机检C1/C2/C4/C6 每个拍板点多人格规则审查（编剧/观众/制片/选角/造型/统筹/摄影/配音）；真 LLM 到位换 lane 不换骨架
影子记账Σbilling == episode.cost_cents 对账不变量；免费任务不记不计；用户面只显示「自部署·高价值档」
